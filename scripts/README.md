### Load calculation

`load_settings()` reads 498 bytes individually. A one-byte random read with a
16-bit address transfers five I2C bytes (control-write, two address bytes,
control-read, and data). Including ACK/NACK bits, that is 45 SCL clocks:

`498 bytes * 45 clocks / 100,000 Hz = 224.1 ms`

### Mass erase calculation

`settings_erase_eeprom()` performs 498 separate byte writes. The current driver
does a readiness check followed by a four-byte write transaction, totaling about
45 SCL clocks per byte, and waits for the EEPROM's internal write cycle after
every byte:

- I2C bus time: `498 * 45 / 100,000 = 224.1 ms`
- Typical: `0.2241 s + 498 * 3 ms = 1.72 s`
- Maximum: `0.2241 s + 498 * 5 ms = 2.71 s`

These are protocol estimates. STM32 HAL/software overhead and additional ACK
polls can make measured times slightly longer. The 3 ms typical and 5 ms maximum internal
write-cycle values are the timing assumptions for the 24CW1280T-I/OT.
